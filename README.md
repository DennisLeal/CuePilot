# CuePilot — AI Interview Copilot (Zelven Labs)

CuePilot is a real-time, local-first AI-powered desktop teleprompter designed to help job seekers structure STAR-method answers on the fly and maintain natural eye contact during video interviews.

## Features
- **Local-First Processing:** Runs locally on PC hardware via Ollama.
- **Dual Interface:** Control center dashboard + floating, always-on-top webcam overlay.
- **STAR Answer Structuring:** Instant situational talking points formatted for rapid reading during live interviews.
